## 视觉与交互

对照本机 PI 的 user-message、assistant-message、footer、tool 与主题实现，采用平面消息、连续助手正文、折叠思考与工具、小型 footer。颜色优先跟随 VS Code；没有复制终端主题协议。

Browser 插件不可用，因此用 Playwright Core 和本机 Edge 加载实际构建产物，注入模拟 VS Code API 和对话夹具。验证暗色、浅色和高对比度主题，各 320px / 480px 宽度，以及等效 200% 缩放（240×450 有效 CSS 视口），九种截图全部通过无横向溢出断言。浏览器中验证中文组合输入的 Enter 防误发、斜杠菜单、发送/确认和无页面异常。修复了 200% 等效布局下标题菜单挤出视口的问题。

截图保存于仓库 `docs/screenshots/`（仅源码仓库包含，VSIX 不包含）；这是浏览器夹具截图，不是 VS Code 原生侧栏截图，也不代表已完整覆盖操作系统缩放、屏幕阅读器和真实 VS Code 所有主题。

## 包与安全边界

VSIX 只包含 manifest、README、许可证、宿主/Webview bundle、样式、图标及本验证记录。PI 安装副本、模型凭证、会话文件、源映射、测试夹具和开发依赖均不打包。`npm audit --omit=dev` 为 0 个漏洞；开发工具链的 glob/minimatch 相关 moderate advisories 不进入 VSIX。

Webview 使用 CSP、清洗后的 Markdown、受限 URL 和 action 白名单；Webview 不能指定任意文件路径或启动任意宿主命令。文件读取与进程创建在扩展宿主完成，工作区需为本地且受信任。
