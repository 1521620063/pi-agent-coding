## 问题与处理

- 首次原生宿主测试发现，原测试启动器将机器级 PI 路径写在工作区设置中，VS Code 未使用该路径，导致误连本机 PI，并执行了模型轮换，可能改变 PI 的默认模型。未猜测或改写原模型值。现已改为每次运行创建独立用户配置，并断言当前模型必须为 fake；后续 7 项宿主测试使用模拟 PI 通过。
- 主题截图最初在按钮颜色过渡动画期间抓取，出现暂时偏暗；夹具禁用截图期间的过渡并校验最终计算颜色，12 组通过。
- 分叉在可见用户消息与 PI 分叉点数量或文本不一致时拒绝映射，引导使用 PI 提供的分叉菜单，避免选错分叉点。
- 补全在附件确认前保留原输入；确认后不覆盖新草稿，并关闭已过期候选。历史上下键支持多行历史返回原草稿。
- 320px / 200% 缩放下输入工具组曾出现挤压，已让工具组按实际可用宽度换行；浏览器额外断言附件、发送方式与发送按钮均在输入区边界之内，12 组通过。
- 独立审查代理未返回实际审查内容，未将其记为已通过；已对协议边界、文件访问、异步状态及 UI 交互进行本地复核和回归测试。
